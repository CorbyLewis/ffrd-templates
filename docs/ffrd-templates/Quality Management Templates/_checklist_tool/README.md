# FFRD Review Checklists (browser tool)

Open `FFRD-Review-Checklists.html` in Microsoft Edge or Google Chrome. It's a single file: no install, no server, and nothing is uploaded. Create or open a project folder and work through the checklists; your work is saved as files in that folder.
